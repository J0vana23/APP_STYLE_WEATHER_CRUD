# Style Weather App 🌤️👗

Aplicativo Android em **Kotlin** com **Jetpack Compose** para organização de roupas por estação do ano.  
O app utiliza **Firebase** para autenticação, armazenamento de dados e gerenciamento de roupas e usuários.

---

## 💡 Funcionalidades

1. **Autenticação Firebase**
   - Cadastro e login de usuários com email e senha.
   - Logout direto do app.
   - Gerenciamento de conta pelo Firebase.

2. **Gerenciamento de Roupas**
   - Listagem de roupas cadastradas.
   - Adição de novas roupas.
   - Edição de roupas existentes.
   - Exclusão de roupas.
   - Feedback via Snackbar para ações concluídas ou erros.

3. **Tela de Configurações**
   - Listagem de roupas em cards com gradiente roxo.
   - Botão "Sair da conta" centralizado e grande (cinza).
   - Cards com botões "Editar" e "Excluir".

4. **Editar Perfil**
   - Alteração de nome e senha do usuário.
   - Botão "Salvar alterações" com gradiente roxo.
   - Layout limpo e centrado.

5. **Home**
   - Exibição das roupas cadastradas em cards coloridos.
   - Interface organizada e responsiva.
   - Gradientes e cores para uma experiência visual agradável.

6. **Snackbars**
   - Mensagens de sucesso ou erro nas ações do usuário.

---

## 🖼️ Telas do App

1. **Login**
   - Campos de email e senha.
   - Botão para login e link para cadastro.
   - Gradiente roxo moderno.

2. **Cadastro**
   - Nome, email, senha e confirmação.
   - Integração com Firebase Authentication.

3. **Home**
   - Listagem de roupas cadastradas.
   - Cards com gradiente, detalhes da roupa e ação de editar/excluir.
   - Layout limpo e centralizado.

4. **Configurações**
   - Cards de roupas como na Home.
   - Botão "Sair da conta" em cinza.
   - Título centralizado e visual organizado.

5. **Editar Perfil**
   - Formulário para alterar nome e senha.
   - Botão "Salvar alterações" com gradiente.
   - Layout limpo, itens centralizados.

---

## 🛠️ Tecnologias Utilizadas

- **Kotlin**: Linguagem principal.
- **Jetpack Compose**: UI moderna e responsiva.
- **Firebase Authentication**: Login e cadastro de usuários.
- **Firebase Firestore**: Banco de dados em tempo real para roupas.
- **Snackbars**: Feedback visual para o usuário.
- **Gradle**: Build do Android Studio.
